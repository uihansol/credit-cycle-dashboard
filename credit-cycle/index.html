원의 색은 연도(과거 → 최근 그라데이션), 원의 크기는 그 시점의 VIX입니다 — 큰 원이 이어지는 구간일수록 시장 변동성이 커서 궤적이 빠르게 움직였습니다. 빨간 테두리 원이 현재 위치, 회색 화살표는 신용 사이클의 일반적인 순환 방향(#1 위험 → #2 회복 → #3 확장 → #4 둔화)입니다. VIX 값이 없는 시점(1990년 이전, 휴장일 등)은 작은 회색 테두리 원으로 표시합니다. ‘▶ 흐름 재생’을 누르면 과거부터 현재까지 점이 시간순으로 찍혀 가는 모습을 볼 수 있습니다.

점은 과거(연함) → 최근(진함) 순서로 이어지며 빨간 점이 현재 위치입니다. 오른쪽으로 갈수록 신용스프레드가 넓고(신용 경계), 위로 갈수록 장단기 금리차가 큽니다(커브 가파름). 점선은 장단기 역전선입니다. 보라색 점선이 과거 유사 국면으로 본 예상 경로입니다. 드래그로 확대, 더블클릭으로 원래대로.

회색 음영은 NBER이 판정한 경기침체 구간, 보라색 부채꼴은 전망 범위(진한 부분 25–75%, 연한 부분 10–90%)입니다.

전망은 어떻게 계산하나요?
  1. 유사 시점 찾기 — 전체 이력에서 현재와 위치(가로·세로 값)와 최근 6개월 흐름(방향·속도)이 가장 비슷한 과거 시점을 찾습니다. 같은 사건이 여러 번 뽑히지 않도록 서로 12개월 이상 떨어진 시점만 고릅니다.
  2. 경로 옮겨 붙이기 — 각 유사 시점 이후 실제로 움직인 궤적을 현재 위치에 옮겨 붙입니다 (비율 지표·하이일드 스프레드는 변화율로 적용).
  3. 평균·범위·가능성 — 가까운 시점일수록 큰 가중치로 평균해 예상 경로를 만들고, 경로들이 흩어진 정도로 범위를, 끝점이 속한 4분면으로 국면별 가능성을 셉니다.
  4. 침체 동반 비율 — 그 유사 시점들 이후 전망 기간 안에 NBER 경기침체가 있었던 비율을, 평소(전체 이력) 비율과 함께 보여 줍니다.

계산에는 기준 시점 이전에 알 수 있던 정보만 씁니다. 종료일을 과거(예: 2007년, 2019년)로 옮기면 그 시점에서 이 방법이 무엇을 가리켰는지 되짚어 볼 수 있습니다. 하이일드(V6)·BBB(V7)는 ICE BofA 시리즈라 FRED 공개 기간이 짧을 수 있어, 겹치는 기간의 관계로 Baa−10Y 장기 이력을 해당 지표 척도로 환산해 과거 유사 시점을 찾습니다.

통계적 예측 모형이 아니라 “역사가 비슷하게 흘러간다면”이라는 참고용 시나리오입니다. 투자 판단의 근거로 쓰지 마세요.

데이터 출처: FRED (저장소에 보관된 CSV)

브라우저는 이 저장소의 ./data/*.csv 파일만 읽습니다. 데이터는 GitHub Actions가 평일 하루 두 번(FRED 발표 직후 포함) 갱신하고, 제목 옆 ↻ 버튼으로 지금 바로 갱신을 요청할 수도 있습니다.

서버에서 최신 데이터 받기

브라우저는 FRED에 직접 접속하지 않습니다. ↻ 버튼은 이 저장소의 GitHub Actions를 실행해 서버가 FRED에서 새 값을 받아 CSV를 갱신하게 한 뒤, 갱신된 CSV를 다시 읽어 옵니다. 이를 위해 GitHub 토큰이 한 번 필요합니다.

  1. GitHub → Settings → Developer settings → Fine-grained personal access tokens → Generate new token
  2. Repository access: Only select repositories → 이 저장소만 선택
  3. Permissions → Repository permissions → Actions: Read and write (그 외 권한은 필요 없음)

토큰은 이 브라우저(localStorage)에만 저장되고, 서버 갱신을 요청할 때 GitHub에만 전송됩니다. 공용 컴퓨터에서는 저장하지 마세요.

토큰이 없어도 GitHub Actions 페이지의 “Run workflow”로 직접 갱신할 수 있습니다.
